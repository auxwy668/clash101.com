常见问题

Clash 是什么？和普通 VPN 有什么区别？ ▼
Clash 是一个基于规则的代理客户端，不是传统 VPN。它能智能分流国内外流量——国内网站直连访问、国外网站走代理通道，互不干扰。相比 VPN 的"全局代理"模式，Clash 的规则分流更灵活、速度更快、对正常上网影响更小。详见 Clash 新手入门完全指南。
Clash Verge Rev 怎么导入订阅链接？ ▼
打开 Clash Verge Rev → 点击左侧「订阅」→ 点击右上角「新建」→ 粘贴机场提供的订阅链接 → 保存。Clash 会自动拉取节点列表。如果导入失败，检查链接是否完整、网络是否正常、机场是否支持 Clash 格式。详见 Clash Verge Rev 使用教程。
TUN 模式是什么？需要开启吗？ ▼
TUN 模式会在系统网络层创建虚拟网卡，接管所有程序的流量。普通模式下 Clash 只能代理浏览器和应用层流量，但开启 TUN 后，命令行工具、游戏、系统更新等也能走代理。如果你发现某些软件不走代理，开启 TUN 模式通常能解决。详见 Clash TUN 模式完整指南。
Clash 连不上/代理不生效怎么办？ ▼
先检查三点：1）系统代理开关是否打开；2）节点是否在线可选；3）规则配置是否正确。常见解决方案：切换节点、开启 TUN 模式、检查防火墙是否拦截、更新 Clash 内核。完整排查步骤见 Clash 连接故障排查指南。
Clash 规则分流怎么配置才能不干扰国内网站？ ▼
默认规则已内置 GEOIP 和常见域名分流，绝大多数情况下无需修改。核心逻辑：GEOIP,CN,DIRECT 让所有中国 IP 直连；DOMAIN-SUFFIX,google.com,PROXY 让 Google 走代理。如需自定义规则，在「规则」页面添加即可。详见 Clash 规则分流配置指南。
Clash Verge Rev、ClashX、Mihomo Party 哪个最好用？ ▼
Windows 用户推荐 Clash Verge Rev（开源、稳定、中文界面）；macOS 用户可选 ClashX Meta 或 Clash Verge Rev；Android 推荐 FlClash。Mihomo Party 适合需要多机场管理和高级配置的用户。所有客户端都可以导入相同的 Clash 订阅。详见 Clash 客户端对比与选择指南。
